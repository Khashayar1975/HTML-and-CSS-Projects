How to open the website
-----------------------
1. Open the Khashayar-Portfolio folder.
2. Double-click index.html.
3. The website will open in your browser.

How to upload to GitHub
-----------------------
1. Create a new public GitHub repository for the portfolio.
2. Upload all files and folders without changing the folder structure.
3. Make sure index.html is located in the repository root.
4. Open repository Settings.
5. Select Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select the main branch and /(root).
8. Click Save.
9. Wait a few minutes for GitHub Pages to publish the website.
